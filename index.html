how this works / limitations
This page runs entirely in your browser — there's no backend, so you can host it on any free static host (GitHub Pages, Cloudflare Pages, Netlify, Vercel, surge.sh...) and it works as-is.

It turns your sentence into a path on archive.mozilla.org, always under /pub/firefox/candidates/<version>-candidates/build<N>/<platform>/<locale>/ — that tree holds every build, including final releases before and after they go live, so it's used for beta / rc / esr / release alike rather than the separate releases/ mirror. Developer Edition ("devedition" / "deved" / "aurora" / "dev") is fully supported too — it's the same beta build, just published from its own root instead: /pub/devedition/candidates/<version>-candidates/....

To find the exact filename (it isn't always predictable) the app tries to read that folder's real directory listing through a public CORS proxy, since Mozilla's archive doesn't send CORS headers itself. If every proxy is unreachable from your network, it falls back to a best-guess filename built from Mozilla's normal naming pattern, clearly marked guess — it's usually right, but worth checking against the manual browse link if the download 404s.

Tested against beta / rc / esr / release / devedition channels. Nightly uses a different archive layout and isn't handled yet.
